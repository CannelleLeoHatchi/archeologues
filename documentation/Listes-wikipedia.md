# Listes Wikipédia de la population étudiée

## Sources Wikipedia

La population étudiée comprend des archéologues classiques spécialisés dans les civilisations grecque et romaine antiques, ayant exercé leur activité à partir du XIXe siècle. La principale source pour identifier cette population est la catégorie anglophone de Wikipédia : 

https://en.wikipedia.org/wiki/Category:Classical_archaeologists 
Cette catégorie peut être complétée par plusieurs sous-catégories nationales : 
https://en.wikipedia.org/wiki/Category:American_classical_archaeologists 
https://en.wikipedia.org/wiki/Category:British_classical_archaeologists 
https://en.wikipedia.org/wiki/Category:German_classical_archaeologists.
Les biographies Wikipédia serviront à identifier les individus et à recueillir les premières informations concernant leurs parcours, leurs formations, leurs institutions et leurs activités scientifiques.
